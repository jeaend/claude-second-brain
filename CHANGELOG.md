# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-05-23
- Initial public marketplace scaffold (`.claude-plugin/marketplace.json`).
- Added `career` plugin (`plugins/career/.claude-plugin/plugin.json`).
- Added first skill: `career/brag-board` — captures professional accomplishments to a personal brag doc, with daily cron + on-demand backfill modes, per-day scan, source-ID dedup, optional sync targets, and a rich entry shape designed for downstream summary/CV/perf-review skills.
- Added `CLAUDE.md` with skill shape, writing principles, sensitive-content checklist, and spec references.
- Added `README.md` with overview table, per-plugin dropdowns, and contributor pointers.
